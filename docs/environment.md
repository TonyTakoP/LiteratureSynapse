# 宿主能力、安裝與降級

確認日期：2026-11-10（Asia/Taipei）。能力與權限會依工作階段改變，使用前重新確認，不從 Skill 文字推定工具存在。

## Skills 規範

依 [官方 Skills 文件](https://learn.chatgpt.com/docs/build-skills) 與 [撰寫指引](https://developers.openai.com/plugins/build/skills)：每份 Skill 有 `SKILL.md`、必要 name／description；支援明確指定與描述匹配，完整內容按需讀取。本專案採 `.agents/skills/技能名稱/SKILL.md`，不建立選配 YAML 或 Plugin。

Codex CLI／IDE 可用 `$技能名稱` 或 `/skills` 選擇；其他介面使用其實際技能選單。若未顯示，先重新開啟工作階段／重新啟動 Codex，再確認工作目錄為 LiteratureSynapse 根目錄；不要自行修改全域設定或複製到使用者技能目錄。同名技能不會合併，選用時檢查路徑。

本輪能寫入並直接讀取專案 Skill 檔案，但沒有可查詢 IDE 技能選單的原生工具；這不能證明宿主已自動註冊。新工作階段應確認六項技能出現，再以自然語言及明確指定各試一次，結果記在 [驗收紀錄](acceptance/results.md)。若只手動讀取成功，應標示「手動載入驗證」，不能稱為自動觸發成功。

本輪驗收中，一般沙箱終端曾回報 `setup refresh had errors` 而無法啟動；經既有權限審查允許的單次原生讀取／搜尋／複製可繼續操作。這是當次工具狀態，不是 Skill 可提升權限的能力；未來遇到權限不足仍依宿主流程處理，不能由文件授權繞過。

## 能力矩陣

| 能力 | 本輪狀態 | 使用方式／降級 |
| --- | --- | --- |
| 本地 Markdown 讀取與搜尋 | 已驗證 | 宿主檔案工具、單次既有指令；工具不足時逐檔閱讀並揭露範圍。 |
| 專案 Markdown 寫入／讀回 | 已驗證 | 宿主文件編輯工具；權限不足時交付聊天草稿，不能稱為已儲存。 |
| 網路搜尋與公開網頁閱讀 | 規劃輪已驗證 | 只在指定公開來源／要求補查時使用；離線時保留缺值並請使用者提供摘錄。 |
| 本地 PDF 免程式碼閱讀 | 未驗證 | 僅用當次已提供的原生閱讀能力；否則請提供文字／摘錄，不執行 parser 或 PDF Skill 的腳本。 |
| Mermaid 預覽 | 未驗證 | 交付 Markdown 原始碼，標記未經渲染驗證；使用者可在既有編輯器預覽。 |
| 原生免程式碼 SVG 匯出 | 未驗證／非預設 | 不安裝、不使用 CLI 轉換；只有能力已確認且另授權才輸出。 |
| Git／檔案歷史 | 本資料夾未啟用 Git；歷史未知 | 不自行 git init／commit；高風險變更採逐檔 Markdown 備份，備份失敗不覆寫。 |
| 跨 Skill 載入 | 可由宿主直接讀取文件 | 由 Agent 按需依序讀取，不假設 Skill 呼叫 API／工作佇列存在。 |
| 監控、排程、雲端同步 | 不納入 MVP | 使用者明確要求後才更新；不自行建立服務或外部連線。 |

## 本專案驗證方法

只以宿主檔案工具、單次讀取／搜尋及人工／Agent 檢查 Markdown；不用 skill-creator 初始化／驗證腳本，不編寫測試程式。正式來源預設空白，驗收全部在 `docs/acceptance/` 隔離執行。

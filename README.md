# LiteratureSynapse

以本地 Markdown 保存研究資料、以 Codex Agent Skills 定義工作流程的個人研究知識庫。不需啟動 App、CLI 或服務，也沒有自訂程式碼。

## 碩士論文研究目標

**已確定題目：企業 AI Agent 之任務完成率與回答可靠性評估。**

目前依初次會議共識，先針對 Agent 回答正確率進行文獻回顧。每篇相關文獻逐步累積問題、主張、證據與知識圖譜，支援後續碩士論文撰寫；企業場景、最終指標與實驗設計仍待確認。

往後可直接說「整理這篇論文，納入我的碩士研究」。本論文相關文獻預設一併更新筆記、台帳、主題摘要與圖譜；若只想保存，請說「這次只存筆記」。具體流程見[逐篇累積約定](docs/conventions.md#本論文逐篇累積約定)。

## 開始使用

在 Codex 開啟本資料夾，確認技能選單列出本專案六個 Skills；若尚未出現，重新開啟工作階段。新技能的自動發現須依 [環境說明](docs/environment.md) 在實際宿主驗證，不能只以檔案存在推定成功。

可直接說：

- 「整理這篇與回答正確性相關的文獻，納入我的碩士研究：……」
- 「把以下摘要整理成 Paper，這次只存筆記：……」
- 「記錄今天跟教授討論的重點：……」
- 「保存這個靈感，暫時不要指定主題：……」
- 「找出該主題提到 LLM-as-a-Judge 的 Paper。」
- 「更新該主題摘要，再依既有台帳產生 Mermaid 圖譜。」

也可明確指定 `$literature-synapse` 或 `$note-capture` 等本專案 Skill。已知的單一任務直接使用對應 Skill；入口處理混合或不明確任務。

## 使用原則

筆記與人工整理的台帳保留來源，彙總及圖譜可重建。主題文件的人工區不被重建；要長期保留的文字放在人工區。本論文文獻整理依已確認約定一併更新摘要／圖譜；其他筆記依本次指示處理。檔案不受背景監控，手動改檔後須再要求更新。

改寫既有筆記、補引用、確認推論關聯與批次改寫，先展示具體變更再確認。私人資料留在本地；不建立腳本、安裝套件、建立資料庫或上傳私人內容來補足工具能力。Mermaid 是正式圖譜來源，SVG 僅為有原生支援時的選配。

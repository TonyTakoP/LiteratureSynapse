### 研究觀點

- **來源報告：** 文字相似度不足以代表事實正確；自動評審需要人工核對；RAG 仍受證據品質限制。對應 [C-20261111-001](../references/entities.md#c-20261111-001)、[C-20261111-002](../references/entities.md#c-20261111-002)、[C-20261111-003](../references/entities.md#c-20261111-003)。三項為 Survey 的已讀轉述，不是本研究的新實驗結果。
- **使用者方向：** 先回顧回答正確率文獻，再為完整論文題目累積資料。[使用者轉述](../notes/papers/N-20261111-001.md#研究背景與教授會議共識)
- **Agent 綜合推論／待確認：** 回答、主張、檢索與操作結果宜分別記錄；實際企業場景與指標尚待選定。[筆記中的操作化建議](../notes/papers/N-20261111-001.md#與論文題目的連結agent-建議尚待確認)

- **新增來源報告：** Harness 提供七面向分類，但 Listing 3 仍是未驗證企業效能的示意骨架。見 [C-20261111-004](../references/entities.md#c-20261111-004)、[C-20261111-005](../references/entities.md#c-20261111-005)。
- **使用者實作方向：** 預計以 Harness Engineering 為基礎；不是教授建議或已定技術選型。[個人評析](../notes/papers/N-20261111-002.md#個人評析)
- **Agent 跨文獻整理／待驗證：** code retrieval 與企業文件 RAG 的任務不同，先列適用性問題，不建立兩文獻互相矛盾的結論。[跨文獻討論](../notes/papers/N-20261111-002.md#與既有文獻的關係)

- **新增來源報告：** 原始模型少追問、DialogGRPO 改善探詢及需求覆蓋、MultiWOZ 有任務完成轉移結果，分別見 [C006](../references/entities.md#c-20261111-006)、[C007](../references/entities.md#c-20261111-007)、[C008](../references/entities.md#c-20261111-008)。追問比例、需求覆蓋、事實正確與外部任務成功須分開解讀。[指標證據](../notes/papers/N-20261111-003.md#e004)
- **Agent 綜合推論／待驗證：** 可在 Harness 候選系統中比較澄清策略，再用 Survey 的評估概念核對回答；這是研究用途分工，未聲稱三篇互相引用或已共同實測。[後續實驗候選](../notes/papers/N-20261111-003.md#後續實驗候選)

### 研究靈感

**Agent 建議／待驗證：** 可考慮在同一企業任務中分開觀察答案正確、證據支持及操作完成，分析三者是否一致；目前僅為研究問題延伸，無實驗證據，不視為教授已同意的設計。[筆記建議](../notes/papers/N-20261111-001.md#與論文題目的連結agent-建議尚待確認)

**新增 Agent 建議／待確認：** 固定模型、企業任務與預算，比較最小執行層、證據檢索及回答驗證等版本，同時觀察任務結果與回答。這是後續實驗候選，未實作且未經教授確認。[實驗候選](../notes/papers/N-20261111-002.md#後續實驗候選)

**新增 Agent 建議／待確認：** 在相同任務與預算下比較直接回答、追問提示、必要欄位追問及依問題價值追問；同時計算需求滿足、事實正確、外部任務成功與互動成本，並加入完整控制組、拒絕補充及改變需求的使用者條件。[探詢實驗候選](../notes/papers/N-20261111-003.md#後續實驗候選)

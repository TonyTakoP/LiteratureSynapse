# 主題彙總

## 輸入與參考

輸入為唯一主題 ID／名稱、可選的包含子主題要求。先讀 [共用規範](../../../docs/conventions.md) 的資料邊界、主題彙總、關聯契約、變更審核及來源品質；讀 [主題模板](../../../templates/topic.md) 了解固定生成章節。由 Skill 向上三層定位根目錄。

## 前置檢查

讀完整主題原檔，確認唯一 T ID、summary_path 指向自身，MANUAL／GENERATED 各一組且不交錯。缺標記、重複、版本不明或已知人工內容混入生成區時停止覆寫，先展示修復草案。不能假稱可偵測所有人工編輯。

只用宿主既有閱讀／搜尋／編輯能力；沒有工具時依 [環境降級](../../../docs/environment.md) 提供未存檔草稿，不寫一次性資料整理程式。

## 工作流程

1. 重新搜尋 notes 中直接包含目標 T ID 的 topic_ids，讀取原始筆記。預設不納入子主題；使用者要求時沿 parent_id 擴展並檢查循環。正式操作排除模板、驗收與備份；明確隔離驗收依共用規範切換資料根。封存資料可列歷史，須明記狀態。
2. 讀相關 Q／C 實體及有關聯的證據。台帳不存在代表尚未整理，不自行補建；不要只憑舊彙總或圖譜當來源。
3. 逐筆整理實際閱讀範圍與證據定位，辨識共識、差異、研究條件、使用者看法及教授建議。對失效／已變更的關聯證據重驗，不能沿用不可信 confirmed；依共用規範列待審草案而非默默改台帳。
4. 產生模板的全部章節。方法比較保留任務、資料、指標及限制；不同條件不得直接比較高低。所有關鍵論點附 N／E 或實體來源連結，Agent 綜合判斷另標示。缺資料寫目前無來源。
5. 來源索引與覆蓋紀錄包括已讀 ID、當時 updated、未讀範圍、缺漏、衝突及是否含子主題。上下文不足分批；尚有缺漏時標示部分彙總，不稱為完整研究現況。
6. 寫前再讀主題，確認人工區與草案基準未變。只替換 GENERATED 內文及 updated；保留 MANUAL 與區外原文，不藉格式化重寫整檔。若需要修正主題名稱／關鍵字，另列建議。
7. 寫後讀回整檔，逐段對照人工區及區外內容不變、所有連結可定位；來源清單應包含新增歸屬、排除已移除歸屬。不要自動更新圖譜。

## 輸出與失敗處理

回覆主題連結、本次新增／變動重點、來源覆蓋、衝突及待確認事項，指出圖譜未更新。已明確要求的合法生成區更新可直接完成；修復標記、修改原始筆記／台帳或人工文字須先審核。

來源不可讀時保留可追溯部分並顯示缺漏；關鍵資料不足則先交付草案。寫入失敗後重讀，確定是否部分變更再續接，不宣稱交易回滾成功。

## 範例

- 「更新可靠性主題摘要」：直接歸屬來源，更新唯一主題文件生成區。
- 「連子主題一起更新」：明記擴展範圍，仍不改子主題原檔。
- 「修改來源後重新彙總」：重讀來源並反映差異，保留人工區。
- 「兩篇結果衝突就選一個」：呈現條件與雙方證據，不臆造共識。
